# Privacy Policy

**Effective date:** November 8, 2026

This Privacy Policy explains how Mail Tool accesses, uses, stores, and shares
information when the account owner authorizes it through Google OAuth.

## 1. Information Mail Tool accesses

Mail Tool requests only this Google OAuth scope:

https://www.googleapis.com/auth/gmail.send

The scope permits Mail Tool to send email as the authorized account. Mail Tool
does not request access to read the inbox, search messages, modify labels,
access contacts, delete mail, or manage the Gmail account.

To deliver a requested message, Mail Tool processes the recipient address,
subject, message body, and any attachment supplied for that message.

## 2. How information is used

Information is used solely to compose and send the email or attachment requested
by the account owner. Mail Tool does not use Gmail data for advertising,
profiling, credit decisions, or training machine-learning models.

## 3. Storage and security

OAuth client configuration, access tokens, and refresh tokens are stored on a
user-controlled system. Token files are protected with restricted file
permissions. Access tokens are refreshed only when needed to send email.

Mail Tool does not intentionally retain message bodies or recipient addresses
after delivery. A user-controlled host may retain source reports, message
templates, or operational logs under the account owner's own management.

## 4. Sharing

Mail Tool does not sell, rent, trade, or share Google user data with advertisers
or data brokers. Data is transmitted only:

- to Google's Gmail API to send the requested message;
- to the intended recipient and that recipient's email provider; or
- when required by applicable law.

## 5. Google API Limited Use

Mail Tool's use and transfer of information received from Google APIs adheres to
the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including the Limited Use requirements.

## 6. Retention and revocation

OAuth credentials remain stored until the account owner revokes access or
deletes the token file. The account owner can revoke Mail Tool's access at any
time through the Google Account permissions page:

https://myaccount.google.com/permissions
